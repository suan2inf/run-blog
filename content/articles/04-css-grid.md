## 基础概念

CSS Grid 是二维布局系统，可以同时控制行和列。

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
```

## 网格线

网格线是 Grid 布局的核心概念，我们可以通过网格线编号来放置元素。

## 自动填充

`auto-fill` 和 `auto-fit` 让网格自动响应容器宽度。

## 总结

Grid 加上 Flexbox，CSS 布局已经非常强大。
