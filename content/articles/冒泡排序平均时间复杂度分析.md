# 冒泡排序的平均复杂度，我自己推了一遍（然后发现 Knuth 早就推完了）

冒泡排序大家都熟：最好 $O(n)$，最坏 $O(n^2)$。那平均呢？教材一般一句"平均也是 $O(n^2)$"带过。

这篇想把它推清楚，分成两个问题：

- 平均交换多少次？
- 平均比较多少次？

中间我踩了几个坑，也一起记下来😋

## 1. 先约定冒泡排序的版本

```python
def bubble_sort(a):
    a = list(a)
    n = len(a)
    for i in range(n - 1):
        swapped = False
        # 末尾 i 个元素已经就位
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        # 一整轮没交换，说明已经有序
        if not swapped:
            break
    return a
```

两个细节会影响比较次数：

- 第 $i$ 轮（从 1 开始数）比较 $n-i$ 次
- 有 `swapped` 提前退出

后面所有结论都针对这个版本。下文假设输入是 $n$ 个互不相同元素的均匀随机排列，即 $n!$ 种排列等可能。

## 2. 平均交换次数

### ❌ 第一次尝试：每种情况占 $1/n$

一开始我想按"最好到最坏"列出 $n$ 种情况，每种情况概率 $\frac1n$，再加权求和。

问题在于 $n$ 个元素有 $n!$ 种排列，它们并不会均匀落在这 $n$ 种情况上，所以这个 $\frac1n$ 没有依据。

### ❌ 第二个坑：一轮一轮递推

另一个自然的想法是：跑完一轮，最大值到了末尾，剩下 $n-1$ 个元素再递推。

但跑完一轮后，剩下的元素已经不是均匀随机排列了。$n=3$ 时，6 种排列各跑一轮：

| 初始 | 一轮后 | 前两位 |
|---|---|---|
| 123 | 123 | 12 |
| 132 | 123 | 12 |
| 213 | 123 | 12 |
| 231 | 213 | 21 |
| 312 | 123 | 12 |
| 321 | 213 | 21 |

`12` 出现 4 次，`21` 只出现 2 次。原因是最大值往后冒的时候，路过的元素也被挪动了。

### ✅ 换个顺序：先把最大值单独换到末尾

冒泡的每次交换，都是交换一对相邻的逆序元素。只要每次换的都是相邻逆序对，不管按什么顺序换，总交换次数都一样（下面会解释原因）。

所以可以换一种顺序：不按轮走，先把最大值一路换到末尾。

- 最大值在第 $k$ 位的概率是 $\frac1n$，换到末尾需要 $n-k$ 次，平均 $\frac{0+1+\cdots+(n-1)}{n} = \frac{n-1}{2}$
- 最大值只和自己经过的元素交换，其余 $n-1$ 个元素的相对顺序完全不变
- 从均匀随机排列中拿掉最大值，剩下的仍是均匀随机排列，而且和最大值原来的位置无关

于是可以放心递推：

$$
S(n) = \frac{n-1}{2} + S(n-1),\qquad S(1)=0
$$

$$
S(n) = \sum_{m=2}^{n}\frac{m-1}{2} = \frac{n(n-1)}{4}
$$

$n=3$ 验证：6 种排列的交换次数是 $0,1,1,2,2,3$，平均 $\frac96 = 1.5 = \frac{3\times2}{4}$ ✅

### 回头看：其实就是逆序对

每交换一次相邻逆序对，整个数组的逆序对数恰好减 1。排好序时逆序对是 0，所以

$$
\text{交换次数} = \text{初始逆序对数}
$$

这就是"换顺序不影响总数"的原因。任意一对元素逆序的概率是 $\frac12$，一共 $\binom n2$ 对，期望直接得到 $\frac12\binom n2 = \frac{n(n-1)}{4}$，和递推结果一致。

## 3. 平均比较次数：先定数量级

### ❌ 错误直觉："比较最多比交换多一次"

我一开始觉得，一轮里不交换的比较顶多一次，所以比较和交换只差 $O(n)$。

反例 `[2,3,4,5,1]`：

| 轮 | 比较 | 交换 |
|---|---|---|
| 1 | 4 | 1 |
| 2 | 3 | 1 |
| 3 | 2 | 1 |
| 4 | 1 | 1 |

比较 10 次，交换 4 次。推广到 `[2,3,…,n,1]`，比较 $\frac{n(n-1)}{2}$ 次，交换只有 $n-1$ 次，差距是 $n^2$ 量级。`1` 每轮只能往前挪一格，所以要跑满 $n-1$ 轮，而每轮几乎都在做不交换的比较。

### ✅ 夹逼

- 每次交换前都有一次比较，所以 交换次数 $\le$ 比较次数
- 比较次数最多 $(n-1)+\cdots+1 = \frac{n(n-1)}{2}$

取平均：

$$
\frac{n(n-1)}{4} \le \mathbb E[C] \le \frac{n(n-1)}{2}
$$

两边都是 $n^2$ 量级，所以 $\mathbb E[C] = \Theta(n^2)$。只要数量级的话，到这里就够了。

## 4. 平均比较次数：精确推导

注意：第 2 节"换顺序"的技巧对比较次数不成立。比较次数取决于实际跑了几轮，必须老老实实分析轮数。

### 4.1 换人视角

一轮冒泡里，可以想象手上"拿着"一个数往右走。每次比较只有两种结果：

- 比右边大：交换，继续拿着它往右走
- 比右边小：放下它，换成拿右边那个更大的（换人）

所以每轮里 比较次数 = 交换次数 + 换人次数，而且手上拿的永远是目前为止见过的最大值。

### 4.2 一个数每轮怎么动

对初始排列的第 $i$ 个位置（从 1 开始），定义

$$
b_i = \text{它左边比它大的元素个数}
$$

**引理：** 每跑一轮，所有 $b_i>0$ 的元素恰好左移一格，$b_i$ 恰好减 1；$b_i=0$ 的保持为 0。

- 若 $x$ 左边有比它大的数，那么走到 $x$ 时，手上拿的是前缀最大值，一定比 $x$ 大，于是越过 $x$。$x$ 左移一格，左边比它大的数少了一个。这一轮只有手上那个数会从 $x$ 左边跑到右边，所以 $b$ 恰好减 1
- 若 $b_i=0$，$x$ 本身就是前缀最大值，会被"拿起来"往右走，它越过的数都比它小，$b$ 仍是 0

数组有序当且仅当所有 $b_i=0$。记 $B=\max_i b_i$，那么恰好跑完 $B$ 轮时数组有序，还要再跑一轮没有交换的，才能确认有序并退出。外层循环最多 $n-1$ 轮，所以

$$
R = \min(B+1,\ n-1)
$$

验证 `[2,3,4,5,1]`：`1` 左边有 4 个更大的数，$B=4$，$R=\min(5,4)=4$ ✅

### 4.3 逆序表：$b_i$ 互相独立

$b_i$ 只能取 $0,1,\dots,i-1$，共 $i$ 种取值，所以 $(b_1,\dots,b_n)$ 一共 $1\cdot2\cdots n = n!$ 种。

而且排列和这样的序列一一对应：从右往左看，$a_n$ 是全体元素里第 $b_n+1$ 大的；去掉它，$a_{n-1}$ 是剩下元素里第 $b_{n-1}+1$ 大的；依此类推。这个序列叫逆序表。

因此在均匀随机排列下，$b_1,\dots,b_n$ 相互独立，且 $b_i$ 在 $\{0,\dots,i-1\}$ 上均匀分布。

于是

$$
P(B\le k) = \prod_{i=1}^{n} P(b_i\le k)
= \prod_{i=k+2}^{n}\frac{k+1}{i}
= \frac{k!\,(k+1)^{n-k}}{n!}
$$

前 $k+1$ 个位置怎么取都满足 $b_i\le k$，概率为 1，所以连乘只从 $i=k+2$ 开始。

### 4.4 精确期望

令 $D = n-1-B$，可以理解为"比最坏情况少跑几轮"。代入上式：

$$
t_j := P(D\ge j) = P(B\le n-1-j) = \frac{(n-j)!\,(n-j)^{j}}{n!}
$$

轮数 $R = n - \max(D,1)$，比较次数

$$
C = \sum_{i=1}^{R}(n-i) = \frac{n(n-1) - D(D-1)}{2}
$$

（$D=0$ 和 $D=1$ 时 $D(D-1)=0$，都对应跑满 $n-1$ 轮，正好对得上。）

由 $\mathbb E[D]=\sum_{j\ge1}t_j$、$\mathbb E[D(D-1)] = 2\sum_{j\ge2}(j-1)t_j$，以及 $P(D=0)=1-t_1=\frac1n$，得到

$$
\mathbb E[R] = n + 1 - \frac1n - \sum_{j=0}^{n-1} t_j
$$

$$
\mathbb E[C] = \frac{n(n-1)}{2} - \sum_{j=2}^{n-1} (j-1)\,t_j
$$

这两个式子是精确的，下面的代码会用全排列枚举验证。

### 4.5 渐近

把 $t_j$ 写成连乘：

$$
t_j = \prod_{i=0}^{j-1}\frac{n-j}{n-i} = \prod_{i=0}^{j-1}\left(1-\frac{j-i}{n-i}\right)
$$

当 $j$ 是 $\sqrt n$ 量级时，取对数近似：

$$
\ln t_j \approx -\sum_{m=1}^{j}\frac{m}{n} \approx -\frac{j^2}{2n}
\quad\Rightarrow\quad
t_j \approx e^{-j^2/(2n)}
$$

求和换成积分：

$$
\sum_j t_j \approx \int_0^\infty e^{-x^2/(2n)}\,dx = \sqrt{\frac{\pi n}{2}},
\qquad
\sum_j (j-1)\,t_j \approx \int_0^\infty x\,e^{-x^2/(2n)}\,dx = n
$$

代回去：

$$
\mathbb E[R] = n - \sqrt{\frac{\pi n}{2}} + O(1),
\qquad
\mathbb E[C] = \frac{n^2}{2} - \frac{3n}{2} + O(\sqrt n)
$$

更精细地，$\sum_j t_j$ 正是 Ramanujan Q 函数，有 $\sum_j t_j = \sqrt{\pi n/2} - \frac23 + O(1/\sqrt n)$（TAOCP 1.2.11.3），所以 $\mathbb E[R] = n - \sqrt{\pi n/2} + \frac53 + o(1)$。

数值对照：

| $n$ | $\mathbb E[R]$ 精确 | $n-\sqrt{\pi n/2}+\frac53$ | $\mathbb E[C]$ 精确 | $\frac{n^2}{2}-\frac{3n}{2}$ |
|---|---|---|---|---|
| 100 | 89.066 | 89.134 | 4878.1 | 4850 |
| 1000 | 962.014 | 962.034 | 498595.8 | 498500 |
| 10000 | 9876.329 | 9876.336 | 49985310.0 | 49985000 |

结论：

- 平均几乎总要跑满，只比 $n$ 轮少 $\sqrt{\pi n/2}$ 轮左右
- 平均比较约 $\frac{n^2}{2}$，是平均交换次数 $\frac{n^2}{4}$ 的两倍

## 5. 代码验证

用全排列枚举，对比暴力统计和公式，`Fraction` 保证精确相等：

```python
from itertools import permutations
from math import factorial
from fractions import Fraction


def bubble_sort_count(arr):
    """返回 (比较次数, 交换次数, 轮数)"""
    a = list(arr)
    n = len(a)
    comps = swaps = rounds = 0
    for i in range(n - 1):
        rounds += 1
        swapped = False
        for j in range(n - 1 - i):
            comps += 1
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swaps += 1
                swapped = True
        if not swapped:
            break
    return comps, swaps, rounds


def max_b(p):
    """B = max_i (第 i 个元素左边比它大的个数)"""
    return max(sum(1 for y in p[:i] if y > x) for i, x in enumerate(p))


def t(n, j):
    """t_j = P(D >= j) = (n-j)! (n-j)^j / n!"""
    return Fraction(factorial(n - j) * (n - j) ** j, factorial(n))


def formulas(n):
    ec = Fraction(n * (n - 1), 2) - sum((j - 1) * t(n, j) for j in range(2, n))
    es = Fraction(n * (n - 1), 4)
    er = n + 1 - Fraction(1, n) - sum(t(n, j) for j in range(n))
    return ec, es, er


for n in range(2, 9):
    perms = list(permutations(range(n)))
    total_c = total_s = total_r = 0
    for p in perms:
        c, s, r = bubble_sort_count(p)
        # 轮数公式对每个排列都成立
        assert r == min(max_b(p) + 1, n - 1)
        total_c += c
        total_s += s
        total_r += r

    cnt = len(perms)
    brute = (Fraction(total_c, cnt), Fraction(total_s, cnt), Fraction(total_r, cnt))
    assert brute == formulas(n)
    ec, es, er = brute
    print(f"n={n}: E[C]={float(ec):.4f}  E[S]={float(es):.4f}  E[R]={float(er):.4f}")
```

$n=2$ 到 $8$ 全部通过。

## 6. 从缺陷到改进：我的"分组排序"

推完之后我在想，冒泡到底慢在哪。

一轮遍历下来，它只确定了一个最大值。其他数呢？我们只知道某些数比手上的数小，但这些更小的数彼此之间没有比较过，比它大的数后面还有哪些也不确定。比较得到的信息大部分都浪费了。

于是我想到另一种做法：先取第一个数遍历全组，把比它小的放左边，比它大的放右边，它自己就落在了最终位置上。比如 `3,1,5,4,2`，以 3 为基准，分成 `2,1 | 3 | 4,5`。然后在左右两组里各取一个数，用同样的办法继续分，直到每组只剩一个数。

- 最好情况：每次取的数都恰好在中间
- 最坏情况：每次取的都是最大值或最小值

我给它取名"分组排序"，后来一查，这就是 Hoare 在 1960 年前后提出的快速排序😅

学技术就是这样，自己的奇思妙想经常发现前人早就做过了。不过自己推一遍和直接看结论，感觉完全不一样。
